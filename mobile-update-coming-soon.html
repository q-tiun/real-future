An Insider’s Take

Mobile Update Coming Soon

Over the past few days, developers have quietly teased several features planned for the next mobile update. While none of these changes completely overhaul the app, together they point toward one goal: bringing many of the web experience’s best features to mobile while improving everyday usability.

Notification Controls Are Finally Improving

One of the most requested quality-of-life improvements is finally arriving. Developers confirmed that the next update will include a toggle allowing users to disable the automatic Team Pass and Player Pass notifications that currently turn themselves back on.

For users constantly clearing unwanted alerts, this should make the mobile experience far less frustrating.

Notifications Mobile

A New Card Feature Will Replace the Map

Perhaps the biggest teaser wasn’t about the interface at all. A developer revealed that a brand-new feature centered around playing with cards is currently in development and will eventually replace the existing map.

According to the team, the map was the very first attempt at creating a fun, competitive card experience, but this upcoming feature is expected to take its place. No additional details have been shared yet, making this one of the biggest mysteries heading into future updates.

Cards Map

Tennis Continues to Move Closer

Another mini teaser focused on tennis. Developers shared that the tennis interface is coming together nicely, with one team member saying the UI is going to be “sick.”

While there still isn’t an official launch date, development clearly continues to make progress.

Tennis UI

Audit Logs Are Coming

Moderation tools are also receiving an upgrade. Audit Logs will allow moderators to review administrative activity in one place, including timeouts, kicks, bans, unbans, permission changes, and group updates.

For larger communities, this should make tracking moderation history much easier.

Audit Logs Moderation

Advanced Stats Are Coming to Mobile

One of the web app’s most useful features is finally making its way to mobile. Advanced situational statistics that currently appear above the at-bat screen on web will soon be available in the mobile app, giving users more relevant information while following live games.

Advanced Stats Mobile

Folders and Better Organization

Collection management is getting a significant quality-of-life improvement. The ability to drag groups, reorder them, and combine multiple groups into folders, which already exists on web, is also coming to mobile.

Users with larger collections should find organizing cards much easier once this arrives.

Collection Folders

Quick List Is Also on the Way

Quick List is another feature expected to make the jump to mobile. The addition should make it easier to manage cards directly from the collection experience without having to go through as many separate steps.

Quick List Mobile

More Web Features Are Making the Jump

Taken together, the teasers show a broader push to bring the web experience closer to mobile. Notification controls, organization tools, advanced stats, audit logs, Quick List, tennis, and the upcoming replacement for the map are all part of a much larger mobile-focused update.

There is still no single confirmed release date for every feature listed here, but the development updates make it clear that the next mobile release is becoming a substantial one.
