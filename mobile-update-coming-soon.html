An Insider's Take

Mobile Update Coming Soon

Over the past few days, developers have quietly teased several features planned for the next mobile update. While none of these changes completely overhaul the app, together they point toward one goal: bringing many of the web experience's best features to mobile while improving everyday usability.

Notification Controls Are Finally Improving

One of the most requested quality-of-life improvements is finally arriving. Developers confirmed that the next update will include a toggle allowing users to disable the automatic Team Pass and Player Pass notifications that currently turn themselves back on. For users constantly clearing unwanted alerts, this should make the mobile experience far less frustrating.

Notifications Mobile

A New Card Feature Will Replace the Map

Perhaps the biggest teaser wasn't about the interface at all. A developer revealed that a brand-new feature centered around playing with cards is currently in development and will eventually replace the existing map. According to the team, the map was the very first attempt at creating a fun, competitive card experience, but this upcoming feature is expected to take its place.

No additional details have been shared yet, making this one of the biggest mysteries heading into future updates.

Cards Map

Tennis Continues to Move Closer

Another mini teaser focused on tennis. Developers shared that the tennis interface is coming together nicely, with one team member saying the UI is going to be "sick." While there still isn't an official launch date, development clearly continues to make progress.

Tennis UI

Audit Logs Are Coming

Moderation tools are also receiving an upgrade. Audit Logs will allow moderators to review administrative activity in one place, including timeouts, kicks, bans, unbans, permission changes, and group updates. For larger communities, this should make tracking moderation history much easier.

Audit Logs Moderation

Advanced Stats Are Coming to Mobile

One of the web app's most useful features is finally making its way to mobile. Advanced situational statistics that currently appear above the at-bat screen on web will soon be available in the mobile app, giving users more relevant information while following live games.

Advanced Stats Mobile

Folders and Better Organization

Collection management is getting a significant quality-of-life improvement. The ability to drag groups, reorder them, and combine multiple groups into folders, which already exists on web, is also coming to mobile. Users with larger collections should find organizing cards much easier.

Collections Folders

Quick List Makes the Jump to Mobile

Quick List is also on its way. After opening a pack, users will soon be able to quickly list cards directly from the pack-opening screen, making it faster to get new pulls onto the marketplace.

Quick List Marketplace

Bigger Picture

Rather than focusing on one headline feature, this update appears centered around bringing the mobile app much closer to the web experience. Better notifications, advanced stats, collection folders, Quick List, and improved moderation tools all point toward a more polished app.

The biggest unknown remains the feature set to replace the current map. If it delivers on what developers have hinted at, it could become one of the biggest gameplay additions Real has introduced.
